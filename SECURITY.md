# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x (CE) | Yes |

---

## Reporting a Vulnerability

If you discover a security vulnerability within GelombangMaya Community Edition:

1. Do NOT open a public GitHub issue with exploit details or sensitive proofs of concept.
2. File a GitHub Private Vulnerability Advisory directly under the repository security tab.
3. Include:
   - Vulnerability description and impact
   - Step-by-step reproduction guide or proof of concept
   - Affected files and components
   - Suggested mitigations or patches (if available)

We will review your submission promptly and coordinate a responsible security release.
